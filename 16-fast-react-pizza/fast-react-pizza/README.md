# 🍕 Fast React Pizza Co.

Це повноцінний веб-застосунок для замовлення піци. Проект розроблено з акцентом на сучасні підходи до побудови архітектури у React, включаючи просунутий роутинг, управління глобальним станом та стилізацію.

Додаток дозволяє користувачам переглядати меню, додавати піци до кошика, автоматично визначати свою геолокацію та оформлювати замовлення через взаємодію з REST API.

## 🚀 Основний функціонал

- **Синхронізація меню:** Завантаження актуального меню піц із зовнішнього API.
- **Управління кошиком:** Додавання, видалення товарів та зміна їх кількості. Дані кошика зберігаються глобально.
- **Оформлення замовлень:** Створення нового замовлення з відправкою POST-запиту на сервер та отриманням унікального ID.
- **Геолокація:** Можливість автоматично отримати поточну GPS-адресу користувача для доставки за допомогою Geolocation API.
- **Пошук замовлення:** Перевірка статусу існуючого замовлення за його ID.
- **Пріоритетність:** Можливість позначити замовлення як "пріоритетне" під час оформлення або після нього (оновлення даних на сервері).

## 🛠 Використані технології

- **React 18** (через Vite)
- **React Router v6.4+** — використання `loaders` для отримання даних перед рендерингом сторінки, `actions` для мутації даних та `fetchers` для фонових оновлень.
- **Redux Toolkit** — для управління глобальним UI-станом (кошик товарів, дані користувача).
- **Tailwind CSS** — для швидкої, адаптивної та сучасної стилізації компонентів.

## 📦 Запуск проекту локально

Щоб запустити цей проект на своєму комп'ютері, виконайте наступні кроки:

1. Клонуйте репозиторій: `git clone [https://github.com/ВАШ_ЮЗЕРНЕЙМ/fast-react-pizza.git](https://github.com/ВАШ_ЮЗЕРНЕЙМ/fast-react-pizza.git)`
2. Перейдіть у директорію проекту: `cd fast-react-pizza`
3. Встановіть необхідні залежності: `npm install`
4. Запустіть локальний сервер для розробки: `npm run dev`

## 💡 Основні навички, відпрацьовані в проекті

- Розділення стану на **UI-стан** (управляється через Redux Toolkit) та **стан віддалених даних** (управляється через React Router).
- Робота з асинхронними Thunk-функціями в Redux (для отримання GPS-координат).
- Створення перевикористовуваних UI-компонентів за допомогою Tailwind CSS.
- Обробка помилок завантаження даних за допомогою компонентів Error boundaries у React Router.
