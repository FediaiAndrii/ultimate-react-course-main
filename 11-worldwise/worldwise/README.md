# WorldWise 🌍

A web application that allows users to track their travels, mark visited cities on an interactive map, and keep notes about their trips. Built as a part of the "Ultimate React Course" by Jonas Schmedtmann.

## 🚀 Features

- **Interactive Map:** Click anywhere on the map to select a location and add a new city.
- **Travel Log:** Keep a list of visited cities and countries.
- **Notes & Dates:** Add custom notes and dates to each visited location.
- **State Management:** Complex state managed using Context API and `useReducer`.
- **Routing:** SPA navigation built with React Router.

## 🛠️ Tech Stack

- **React** (Hooks, Context API, `useReducer`)
- **React Router v6**
- **Vite**
- **CSS Modules**

## 💻 Running Locally

1. Clone the repository: `git clone https://github.com/your-username/worldwise.git`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`

_(Note: This version is deployed as a static site, so data is saved locally in the React state during the session)._
